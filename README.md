# CISC 4900 Final Project — Animation Annotation Software Suite

A desktop application designed to streamline the process of **annotating video and animation content**, with an emphasis on **pre-production, review, and quick edits**.

The goal of this project is to provide a lightweight, easy-to-use tool for making notes and visual annotations directly on video content without requiring a full-featured video editing suite.

## Features

* 🎬 **Video Import & Playback**

  * Import video files
  * Play, pause, and navigate through video
  * Frame/time-based seeking

* 📤 **Video Export**

  * Export annotated videos
  * Preserve annotations and edits

* 🔍 **Refined Seeking**

  * More precise timeline navigation
  * Frame-by-frame seeking

* 📝 **Text Annotations**

  * Add text directly to video frames
  * Position and edit annotations

* ✏️ **Pen Tool**

  * Draw directly over video frames
  * Freehand annotations for quick notes and feedback

## Goals

The primary goal is to create a simple and efficient annotation workflow for animation and video pre-production. The application should make it easy to:

1. Import existing video content
2. Navigate through footage quickly
3. Add visual and written notes
4. Make quick edits and annotations
5. Export the resulting work
